# AIS POS Kasir Android — v1.4.0

## ✨ Fitur Baru: Menu Navigasi + 3 Layar Baru

Aplikasi sekarang punya menu navigasi (ikon &#9776; di pojok kiri atas) yang membuka 3 layar baru, menutup sebagian gap dengan versi Desktop:

- **Ringkasan** — omzet, jumlah transaksi, dan item terjual hari ini + daftar produk terlaris.
- **Riwayat Sinkronisasi** — daftar seluruh transaksi tersimpan di perangkat ini (tersinkron maupun masih menunggu), pelengkap fitur offline-first v1.3.0.
- **Log Error** — layar penuh untuk menelusuri seluruh error yang tercatat di perangkat ini, dengan tombol Salin Semua dan Bersihkan Semua.

## Instalasi

Unduh dan pasang `AIS-POS-Kasir-Android-v1.4.0-debug.apk`.
