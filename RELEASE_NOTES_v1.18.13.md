# AIS POS Kasir Android v1.18.13

## Perbaikan

1. Hak akses menu POS Android sekarang mengikuti flag menu Kantin dari grup pengguna.
2. Akun multi-toko dari grup pengguna menampilkan pilihan toko aktif di topbar, dan semua request POS otomatis memakai toko yang dipilih.
3. Metadata APK dinaikkan ke versionName 1.18.13 agar versi yang terpasang sesuai dengan paket rilis.

## Catatan

- Perlu server AIS versi terbaru yang sudah memiliki aksi POS `pilih_toko_aktif`.
